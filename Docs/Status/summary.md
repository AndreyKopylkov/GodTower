## Changed vs. Plan (details in `decisions.md`)

- Level time limits raised and bump knockdown made per-level (≈9 m per bump) — Plan numbers were not winnable with bumps.
- Camera: column ≈20% of screen width (not 10–12%) so the hero stays readable in portrait.
- Assets made procedurally in Blender/Pillow instead of Blender MCP / GPT images / image-to-3D.
- Unused Dustyroom SFX pack removed; tag `v1.0` instead of `v1.0-overnight`.
- M0 files landed in art commit `163e956` (orchestrator staging mistake); webhook registrations restored in M2 (`a100c8d`).
